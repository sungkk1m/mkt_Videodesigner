# kv-loop-reference-motion — 레퍼런스 실측 (D-11)

> **Feature**: kv-loop-reference-motion
> **Date**: 2026-08-26
> **Input**: `ENG250117_… .mp4` — 언더다크 모닥불 루핑, 30MB 이하로 재압축된 사본
> **Method**: Plan §1.3과 동일 — 프레임 차이(YAVG), 휘도, Sobel 에너지 시계열 + 배율 탐색 + 사분면 블록 매칭

---

## 1. 구조

| 항목 | 실측 |
|---|---|
| 포맷 | 1080×1920 · **30fps** · 16.0초 · 480프레임 · H.264/AAC |
| 구성 | **4장 × 2회 반복, 장당 2.0초(60프레임)** — 이 앱의 루핑 기본값(4장·2회)과 동일 구성 |
| 전환 | **전부 하드 컷.** 인접 프레임 차이가 경계에서 26~50(255 스케일), 홀드 내부 중앙값 1.6. 크로스페이드 구간 없음 |
| 시작 | 어둠 + 가우시안 블러에서 열림. 총 ~16프레임, 그중 **블러가 보이는 램프는 ~10프레임** |
| 끝 | f475까지 선명, 마지막 ~4프레임에 블러+어두워짐 (재압축 과정에서 잘렸을 가능성 있음) |
| 타이틀 | "Under Dark" 오버레이가 전체 프레임에 항상 존재 |

컷 위치: n=60, 120, 180, 240, 300, 360, 420 — 오차 0프레임. 세그먼트 시작
프레임 육안 대조로 4장 원화가 2회 반복됨을 확인 (seg0=seg4, seg1=seg5,
seg2=seg6, seg3=seg7).

## 2. 카메라 — 진폭이 우리 출력의 1/7이다

세그먼트 시작 프레임 대비 배율 탐색(중앙 60%, 0.002 간격)과 사분면 블록
매칭(불꽃 영역 제외 5패치, ±9px)의 두 방법이 같은 값을 냈다.

| 세그먼트 | 배율 궤적 (시작→중앙→끝) | 방향 |
|---|---|---|
| seg1 | 1.000 → 0.998 → **0.991** | 줌 아웃, 편도 |
| seg2 | 1.000 → **0.987** → 0.998 | 줌 아웃 후 복귀 — **왕복** |
| seg3 | 1.000 → **1.012** → 1.006 | 줌 인 후 복귀 — 왕복(불완전) |
| seg4 | 1.000 → 0.996 → **0.985** | 줌 아웃, 편도 |

- 진폭은 **±1.0~1.5%** — 1080px 폭에서 11~16px. 우리 현재 출력(10%, 108px)의
  약 1/7이다.
- 방향이 장마다 다르고(인/아웃), 왕복인 장과 편도인 장이 섞여 있다. 디자이너
  프롬프트(모든 장 왕복)는 레퍼런스의 요약이라기보다 **정제된 사양**으로 읽는
  것이 맞다 — 사양을 따른다.
- 팬은 검출되지 않았다 (평균 이동 벡터 |v| ≤ 1px@270).

## 3. 원화 자체가 살아 있다 — 재현 불가능한 층

인접 프레임 차이를 10배 증폭한 히트맵에서, 변화가 세 층으로 분리된다.

1. **파티클** — 불티·반딧불이 화면을 떠다닌다. 점 형태의 밝은 궤적.
2. **불꽃 글로우 펄스** — 모닥불 주변 방사형 halo가 주기적으로 밝아졌다
   어두워진다.
3. **카메라 브리딩** — 캐릭터 외곽선의 전체 프레임 이동 (§2의 1~1.5%).

배율 매칭 잔차가 rms 13~35로 우리 출력(6.6~7.0)의 2~5배인 이유가 1·2다.
**이 두 층은 원화 컴포지션 안의 애니메이션이라, 정지 이미지 3장에 어떤 카메라
워크를 걸어도 재현되지 않는다.** 이번 사이클의 범위는 카메라·컷·블러이고,
파티클 오버레이는 별도 기능 후보로만 기록한다.

## 4. 블러 정량

Sobel 에너지를 휘도로 정규화(페이드는 승산적)하고, 선명한 프레임(n=30)에
`gblur`를 걸어 만든 sigma→에너지 매핑과 대조했다.

| 지점 | 정규화 에너지 | 환산 sigma (1080 기준) |
|---|---|---|
| f7~f8 (측정 가능한 최심점) | 21~22 | **≈ 12~13px** |
| f10 | 25 | ≈ 10px |
| f12 | 33 | ≈ 6px |
| f16~ | 42 (정상치) | 0 |
| f0~f5 | 휘도 3~6이라 측정 불능 | 육안 형태 크기로 **≈ 30px+ 추정** |

- 디자이너의 "amount ≈ 30"은 **CSS `blur(30px)` = 램프 시작값**과 부합한다.
  D-08의 제안값이 실측으로 뒷받침됐다.
- 디자이너의 "duration ≈ 10 frames"는 **30fps 기준**이다 — 레퍼런스가 30fps고
  보이는 램프가 ~10프레임. ms로는 **333ms**. 60fps 렌더에서는 20프레임에
  해당한다. D-07의 기본값은 167ms가 아니라 333ms로 잡는다.

## 5. 판정에 주는 영향

| 결정 | 실측이 말하는 것 |
|---|---|
| D-04 (컷) | 레퍼런스는 100% 컷. 그대로 |
| D-07 (블러 길이) | 단위 ms 유지, **기본값 333ms** (60fps 기준 20프레임) |
| D-08 (블러 세기) | 기본 30px 유지 — 램프 시작값과 일치 |
| D-10 (모션 강도) | 레퍼런스는 1~1.5%로 우리 강도 0.075 상당. 단 레퍼런스는 원화 애니메이션이 생동감을 대신 채우고 있어, 정지 원화에 같은 진폭을 쓰면 정지로 보일 위험이 있다(kv-motion 사이클에서 4%도 "움직였는지 모르겠다"였다). **첫 렌더 검수로 결정** — 예정대로 |
| SC4 | 끝 블러가 ~4프레임로 짧은 것은 재압축 절단 가능성이 있어, 판정 기준은 사양(양 끝 동일 길이)을 따른다 |
