# kv-object-animation — M5 실기기 렌더 판정

> **Feature**: kv-object-animation
> **Date**: 2026-08-27
> **Input**: `uavideo_kvloop_ko_9x16_15s_60fps_2.mp4`(이펙트 on) · `…_3.mp4`(off) — 실기기 Chrome 151(Windows), 라이브 Pages 브랜치 빌드 `cd4de89`. 소다전설 3장 · 2회 · 모션 3/3 · 60fps · Standard. 슬롯마다 파티클+글로우 기본값, 글로우 중심만 원화 광원 위로 드래그(런북 §2)
> **Method**: `artifacts/kv-obj-m5/` — locate(온오프 판별 + 글로우 중심 검출) → scan(풀해상도 |on−off|) → repeat(f vs f+450 — 코덱 노이즈 컨트롤 겸 SC2) → zoomcurve(off 배율 곡선) → analyze
> **Verdict**: **SC1~SC7 전부 PASS. D-05 성능 게이트 확정: on/off 총 시간 차 −2.2% (기준 5%).**

## 1. 환경 — 제품 경로 그대로

진단 로그(`?debug=1`) 두 벌 모두: build `cd4de89`, blockers/warnings 없음,
outputTarget `web-fs`, renderStatus completed. 출력 두 벌 모두 1080×1920 ·
h264(High)/aac · 60fps · 901프레임 · 15.02초 · ≈11.5Mbps.

온·오프 판별은 파일명이 아니라 픽셀로: 이펙트 도달 영역의 평균 luma가
`…_2.mp4` 127.0 vs `…_3.mp4` 108.3 → **on = `…_2`** (진단 로그의 1차 렌더와
일치). 검출된 글로우 중심(원화별): (0.507, 0.740) · (0.471, 0.588) ·
(0.539, 0.554) — 반복 사이클 간 차 ≤ 0.95px.

## 2. 방법 — diff 도메인, 그리고 실측된 노이즈 기준선

두 렌더는 이펙트 층만 다르므로 |on−off|가 곧 이펙트 층 + 코덱 노이즈다 —
M4의 불티/원화 판별 게이트가 통째로 불필요해진다. 두 가지가 이 판정의 축:

1. **"코덱 노이즈 수준"은 선험 임계가 아니라 실측이다.** 같은 영상의 f vs
   f+450(3장×2회 반복, 이펙트는 세그먼트 로컬 프레임 — Design §3.4)은
   콘텐츠가 설계상 완전 동일한 쌍이므로, 그 diff가 같은 카메라 위상에서의
   H.264 노이즈 그 자체다. SC1은 이 컨트롤과 위상별로 대조한다.
   (카메라 이동 속도가 노이즈를 지배한다 — 위상 무시 전역 비교는 오판한다.)
2. **글로우 중심은 드래그돼 있으므로 검출 후 판정.** 초기 홀드(배율≈1)의
   diff를 카메라 역보정 좌표로 누적·블러해 halo 피크를 중심으로 삼고, SC1
   밴드·SC4 예측을 그 중심으로 세운다.

SC1 밴드: 파티클 도달 상자(`kvParticlesReach` 닫힌 식, 기본값에서 x
0.23~0.77W · y 0.242~0.75H) ∪ 글로우 원반(검출 중심 ± 0.18W), 카메라 배율
1.0~1.1 전 구간 스윕 + 코덱 번짐 마진 16px. 북엔드 블러 프레임(전역 필터,
f<26·f≥874)은 제외 — 블러가 이펙트 빛을 밴드 밖으로 합법적으로 번지게 한다.

## 3. 판정 — SC1~SC7

| SC | 결과 | 수치 |
|---|---|---|
| SC1 — 지정 영역 밖 무변화 | **PASS** | 밴드 밖 \|on−off\| 위상별 중앙값 0.11~0.91 luma ≤ 같은 위상 컨트롤 0.65~0.94 (15/15 버킷, 전 세그). 16×16 블록 최대 5.16 vs 컨트롤 5.01 — 국소 누출 없음 |
| SC2 — 결정론 | **PASS** | on 렌더의 사이클 반복 diff: 이펙트 원반 내부 중앙값 1.40 luma = off 렌더의 1.43 (이펙트가 반복 차이에 기여 0). 글로우 중심 사이클 간 ≤0.95px. 비트 동일성 자체는 M0·M2 하네스(sha256)가 기확정 — 여기선 실기기 H.264 경로의 반복 결정론 |
| SC3 — 스크럽 = 렌더 | **PASS** | 환형 luma 펄스 적합: 주기 1296~1313ms(설정 1300), 위상 −5°~−1°(순수 함수 `kvGlowOpacityAt`의 예측 0°) — 세그 6개 전부. 닫힌 식이 예측한 프레임 시계가 인코딩에 그대로 있다. 픽셀 동일성은 M0 게이트 ⑤(0.48/255)가 기확정 |
| SC4 — 카메라 추종 | **PASS** | halo 중심의 정점↔정지 변위: seg0/3 측정 45.4·46.7px vs 예측 45.9px, seg1/4 16.2 vs 16.7px, seg2/5 8.3~8.9 vs 10.1px (오차 0.6~2.8px). 정지-캔버스 가설 잔차 10.2~46.9px — 전 세그 기각 |
| SC5 — 성능 게이트 (D-05) | **PASS** | §4 — 총 시간 차 −2.2% (기준 5%) |
| SC6 — 기존 프로젝트 무영향 | **PASS** (실기기 대조 + 논리) | off 렌더 배율 곡선 1.000→1.0505→1.0995/1.1000→1.0465→1.000 — 이전 사이클 실기기 실측·모델과 차 ≤0.001 (15/15 프로브). 렌더 트리는 `effects.length===0`이면 캔버스 자체가 없고(NFR-O01), 스키마 `.default([])` 유닛 + M2 하네스 재실행 비트 동일이 받친다 |
| SC7 — 회귀 없음 | **PASS** | 유닛 614(42파일) · kv DOM E2E 19 passed·1 skipped(컨테이너 Chromium, kv-loop/motion/effects/reference-motion 4스펙) · tsc+vite build 클린. H.264 렌더 E2E 2건은 이 컨테이너에서 실행 불가(인코더 부재 — 기존 제약, Plan §4.2)이고, 그 판정 항목(1080×1920 · h264/aac · 15.0s)은 실기기 렌더 프로브가 이 문서 §1에서 확정 |

## 4. D-05 — 성능 게이트 확정

진단 로그의 렌더러 자체 타이밍(901프레임):

| 버킷 | on | off | 차 |
|---|---|---|---|
| waitForReady | 168.6ms | 172.1ms | −3.5ms |
| createFrame (래스터화) | 1383.5ms | 1139.7ms | **+243.8ms** |
| addSample (인코드) | 4036.4ms | 4403.1ms | −366.7ms |
| audioMixing | 33.5ms | 33.4ms | +0.1ms |
| **합계** | **5622.0ms** | **5748.3ms** | **−126.3ms (−2.2%)** |

- 게이트(총 시간 차 5% 이내, 카메라 사이클 NFR-R02와 같은 기준) **통과** —
  이펙트를 켠 쪽이 오히려 빠르다(인코더 변동이 지배).
- 이펙트의 실비용은 래스터화 버킷에 격리돼 보인다: +244ms/901프레임 ≈
  **+0.27ms/프레임** — 전부 이펙트로 계상해도 총 렌더의 4.2%. 컨테이너
  상한(transform 하 ≈19~25ms/프레임, 소프트웨어 래스터라이저)은 실기기에서
  두 자릿수 배 소멸 — 블러 사이클과 같은 패턴.
- 렌더는 인코드 지배(addSample ≈72%) — 이펙트·카메라는 병목이 아니다.

## 6. 재현

```bash
cp <on.mp4> artifacts/kv-obj-m5/out/a.mp4     # 또는 KV_OBJ_M5_A/B=<경로>
cp <off.mp4> artifacts/kv-obj-m5/out/b.mp4    # a/b 순서는 무관 — locate가 판별
node artifacts/kv-obj-m5/locate.mjs     # → out/locate.json (온오프·글로우 중심)
node artifacts/kv-obj-m5/scan.mjs       # → out/scan.json (~4분)
node artifacts/kv-obj-m5/repeat.mjs on  # → out/repeat-on.json
node artifacts/kv-obj-m5/repeat.mjs off # → out/repeat-off.json
node artifacts/kv-obj-m5/zoomcurve.mjs  # → out/zoomcurve.json
node artifacts/kv-obj-m5/analyze.mjs    # → out/analysis.json + 판정 요약
```

렌더 mp4는 커밋하지 않는다(각 21MB) — 세션에 다시 첨부해야 한다.
