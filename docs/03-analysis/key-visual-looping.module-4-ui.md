## 2. 도메인 명령 (module-2가 남긴 자리)

UI가 부를 대상이므로 이번 모듈에서 만들었다. 전부 순수 함수이고, 자기 템플릿이 아니면
프로젝트를 그대로 돌려준다 — Day1 명령들과 같은 계약이다.

`setKvImage` · `setKvImageStatus` · `moveKvImage` · `setKvCount` · `setKvLoopCount` ·
`updateKvSlotTransform` · `resetKvSlotTransform` · `setKvKenBurns` ·
`updateKvLoopSettings` · `setKvTitleImage` · `updateKvTitleTransform` ·
`updateKvDisclaimerStyle` (+ `copy.kvLoopDisclaimer`는 기존 `setCopyField` 확장)

세 가지를 특별히 지켰다.

1. **순서 변경은 프레이밍과 모든 언어를 함께 옮긴다** — `slots[i]`와 각 언어의
   `images[locale][i]`가 같은 KV를 가리키므로(D-04), 하나만 옮기면 다음 렌더에서
   엉뚱한 이미지가 엉뚱한 프레이밍으로 나간다. 홀드 시간은 타임라인 위치의 것이므로
   그대로 둔다.
2. **불가 조합은 거부하지, 보정하지 않는다** — Plan L8. `setKvCount(8)`이
   15초·2회에서 프로젝트를 그대로 반환하고, UI가 `kvLoopCombination`의 문장을
   보여준다. 조용히 반복을 줄이거나 장수를 깎는 경로는 코드에 없다.
3. **아무것도 바꾸지 않는 편집은 같은 객체를 반환한다** — `mapKvLoop`이 업데이트
   함수가 되돌려준 설정을 그대로 비교하므로, 범위 밖 순서 변경 같은 no-op이 편집기를
   다시 렌더시키지 않는다.

## 4. 남긴 게이트 — 편집기 수동 통과

Design §11.3의 module-4 종료 조건은 "편집기에서 전 과정 수동 통과"이고, 브라우저가
필요하다. module-3의 두 게이트(수동 MP4 1회, `benchmark:render`)와 함께 확인해야 한다.

사용자 디바이스에서 볼 순서:

1. `npm run dev` → 헤더에서 **키비주얼 루핑** 선택 → 다이얼로그에 9:16 고정 안내가 보이고,
   확인 후 규격 선택기가 9:16만 활성인지.
2. 소재 탭에서 KV 4장 업로드 → 타임라인에 4클립 + 반복 고스트 4클립, 눈금은 15초.
3. 경계를 끌어 1.9/2.4/2.3/3.1초로 맞추고, 미리보기가 그 타이밍으로 도는지.
4. 장수를 8로 바꿔보고 "(길이 부족)"으로 비활성인지, 30초로 올리면 풀리는지.
5. 가로 이미지를 한 장 올려 경고와 `contain` 토글이 뜨는지, 켜면 흐린 배경이 보이는지.
6. 타이틀·고지문구 없이 렌더 → 파일이 나오는지 (**SC5**).
7. 카피 탭에서 고지문구 입력 → 하단에 nowrap으로 붙는지, 24자 넘으면 힌트가 뜨는지.
8. `?debug=1`로 렌더 타이밍을 받아 3장면 15초 Standard와 비교 (**NFR-L01**, module-3 D-07).

## 5. Design에서 벗어난 지점

| # | 설계 | 구현 | 이유 |
|---|------|------|------|
| 1 | KV 순서를 **드래그**로 변경 (§6.2) | ↑/↓ 버튼 | HTML5 드래그 정렬은 상당한 양의 코드이고 키보드 접근성을 따로 만들어야 한다. 버튼은 지금 바로 정확하고 접근 가능하다. 드래그가 필요하면 별도 사이클 |
| 2 | `Timeline`의 `repeat?: {count, cycleMs}` (§6.4) | `repeat?: {count}` | `cycleMs`는 `sections`의 합이다. 같은 값을 두 곳에서 받으면 드리프트할 수 있다 |
| 3 | (설계에 없음) `AudioPanel`에 `bgmOnly` | 추가 | §6.5가 나레이션·더킹 UI를 숨기라고 하는데 패널에 그 수단이 없었다. 기본값 off이므로 기존 두 템플릿의 화면은 그대로다 |
| 4 | (설계에 없음) 자산 패널에 언어 선택기 | 추가 | Plan의 "언어 탭을 바꿔 그 언어의 KV만 교체"가 이 패널에서 일어나는데, 언어 선택이 카피 탭에만 있으면 탭을 왕복해야 한다 |
| 5 | (설계에 없음) 고지문구 글자수 힌트 24자 | 카피 탭 | FR-L11이 "넘칠 때 글자수 힌트"를 요구하지만 기준치가 없었다. 레퍼런스 문구(9자)는 한참 아래이고, 렌더는 줄바꿈하지 않으므로 넘칠 위험이 생기는 지점을 24자로 잡았다 |
| 6 | KV 이미지도 핸들 저장·복구 | 재업로드로 대체 | D-04가 프레이밍을 `slots`에 두므로 **이미지를 다시 올려도 잃는 것이 없다** — 트림도 id 보존도 필요하지 않다. Day1 엔드카드 이미지 슬롯이 이미 같은 정책이고, `useKvLoopAssets`가 `useDay1Assets`의 1/4 크기인 이유다 |
