# kv-object-animation — M4 레퍼런스 실측 (파티클·글로우)

> **Feature**: kv-object-animation
> **Date**: 2026-08-27
> **Input**: `ENG250117_… .mp4` — 언더다크 모닥불 루핑 사본 (1080×1920 · 30fps · 480프레임, [reference-measurement](kv-loop-reference-motion.reference-measurement.md) §1과 동일 구조: 4장 × 2회, 장당 60프레임 하드 컷)
> **Method**: `artifacts/kv-obj-m4/` — 불꽃 위치 탐색(다운스케일 mean×range) → 전해상도 스캔(밝기·이동·채도 게이트 + 연결 성분, 글로우 환형 luma 시계열) → 분석(트랙 필터, 사인 최소제곱 적합)
> **Applies to**: `DEFAULT_KV_PARTICLES` / `DEFAULT_KV_GLOW` (project.ts), `TRAVEL_BASE`/`TRAVEL_SPAN` (effects.ts)

---

## 1. 방법 — 무엇이 파티클이고 무엇이 노이즈인가

픽셀 게이트 하나로는 안 된다는 것이 이 실측의 첫 발견이다. 두 개의 판별 규칙이
연쇄로 필요했고, 각각 실패 사례에서 발견됐다.

| 게이트 | 규칙 | 근거 (probe.mjs / overlay.mjs 실측) |
|---|---|---|
| 픽셀: 밝고 | luma > 90 | 불티는 어두운 원화 위의 광원이다 |
| 픽셀: 움직였고 | 인접 프레임 차 > 45 | 카메라 브리딩은 에지를 프레임당 ≤ ~0.3px만 밀어낸다 — 가파른 에지에서도 차이 ≤ ~45. 파티클은 나타나고 이동한다 |
| 픽셀: 유채색 | max(rgb) − min(rgb) ≥ 24 | "Under Dark" 타이틀 획은 무채색(chroma ≤ 10), 불티는 유채색 — 초록 반딧불 46+, 파란 스파크 85 |
| 트랙: 실제로 이동 | ≥4프레임 트랙의 순변위 ≥ max(5px, 0.6px/프레임), 평균 스텝 0.8~30px | 채도 게이트를 통과하는 마지막 오염원 — 유채색 원화 에지(타이틀 획의 배너 비침, 눈사람 당근코)의 브리딩 잔차 — 는 제자리에서 진동한다. 파티클은 간다 |
| 제외 영역 | 불꽃 코어(세로 2배 타원, r 0.09), y > 0.82 | 불꽃 자체와 지옥 원화의 하단 구운 불길 띠 |

검증은 오버레이 육안 대조(`overlay.mjs` — 검출 블롭을 원본 프레임에 표시)로
했다. 갭 허용 매칭(끊긴 트랙을 2프레임 건너 재획득)은 시도 후 **기각** — 겨울
원화의 제자리 트윙클들이 사슬로 엮여 가짜 고속 트랙이 됐다.

## 2. 불꽃·글로우

### 2.1 위치 — 네 원화 모두 같은 자리

mean×range 탐색 결과 불꽃 중심 (0.51~0.53, 0.73~0.79). 반복 세그먼트끼리
±0.01 이내로 일치.

### 2.2 주기 — 세그먼트별 사인 적합 (a + b·t + c·sin + d·cos, 주기 10~90프레임 그리드)

| 세그 | 주기 | 진폭 (luma) | 스윙 |
|---|---|---|---|
| 0 | 467ms | 2.9 | 2.9% |
| 1 | 1717ms | 11.4 | 14.7% |
| 2 | 1233ms | 7.9 | 7.5% |
| 3 | 950ms | 9.7 | 7.5% |
| 4 | 1633ms | 6.9 | 7.2% |
| 5 | 1250ms | 11.8 | 15.0% |
| 6 | 600ms | 7.1 | 7.2% |
| 7 | 1383ms | 9.2 | 6.9% |

- **중앙값 ≈ 1242ms.** 60프레임 홀드에 1~2주기가 담기는 대역이라 적합이
  고조파에 걸릴 수 있고, 두 저값(467·600ms)이 그 패턴이다(같은 원화의 반복
  세그가 1633·1233ms). 6개 값의 군집은 0.95~1.72s.
- **진폭: 환형(반경 0.045~0.22W) 평균 luma가 ±7~12.** 현 모델의 예측과
  비교하면 — intensity 0.6 × 깊이 0.25 × #ff9a3c(luma 174) × 환형 평균
  기여율 ~0.35 ≈ **±9 luma** — 실측 대역 한가운데다. `intensity 0.6`과
  `0.75 + 0.25·sin`은 교정이 아니라 **실측으로 확정**됐다.
- 반경: 코어 밖 시간 std 프로파일이 r ≈ 0.15~0.25W까지 완만하게 이어진다
  (브리딩·파티클과 섞여 상한은 흐릿하다). 기본 `radius 0.18` 유지.
- **반복 세그의 위상이 서로 다르다** (seg1 −157° vs seg5 +38°) — 레퍼런스의
  이펙트 층은 컷마다 리셋되지 않고 독립적으로 이어진다. 우리 설계는 세그먼트
  로컬 프레임(Design §3.4)이라 같은 원화가 항상 같은 위상을 보인다 — 의도된
  차이로 기록한다.

## 3. 파티클 — 두 집단, 그리고 모델 밖 하나

불티 원화 6개 세그(모닥불 0·4, 초록 반딧불 1·5, 지옥 2·6)의 실측:

| 원화 | 동시 가시 개수 (중앙값) | 지름 중앙값 | 평균색 (블롭) | 스텝 속도 vy 중앙값 / P25 |
|---|---|---|---|---|
| 모닥불 (0·4) | 10~13 | 5.6~6.3px | (175,140,105) 호박색 | 0 ~ −30 / −186 ~ −222 px/s |
| 초록 (1·5) | 5~6 | 6.1~6.2px | (110,167,137) 초록 | −36 ~ −219 / −261 ~ −318 px/s |
| 지옥 (2·6) | 7~10 | 5.0~5.5px | (196,131,86) 주홍 | 0 ~ −30 / −135 ~ −180 px/s |

- **개수**: 앙상블 중앙값 8.5, 모닥불 원화 10~13.
- **크기**: 지름 중앙값 5.85px (IQR ~2~8px, 1080 폭 기준).
- **속도는 두 집단이다.** 표류하는 반딧불(중앙값 0~−36px/s, 좌우 스웨이
  |vx| 27~60px/s)과 불꽃 인근의 빠른 상승 불티(P25 대역 −135~−320px/s).
  단일 "대표 속도"는 없다 — 슬라이더가 두 집단을 양 끝으로 커버해야 한다.
- **수명**: 검출 가능 스팬 중앙값 0.13~0.2s, 최대 0.4~0.7s. 플리커로 검출이
  끊기므로 **하한**이다 — 3프레임 간격 스트립 육안 대조에서 다수가 0.3s 이상
  지속, 페이드 포함 실수명은 ~1초대로 읽힌다. `LIFE 1.5~3.0s`는 유지하되
  실기기 검수(M5)에서 체감 판정.
- 플리커: 긴 트랙의 피크 luma 주기 1.4~4.3Hz (표본 7~19개로 약함).
  `FLICKER_HZ 3` 대역 안 — 유지.
- 분포: 불티 구름 x 0.22~0.85, y 0.27~0.81 (5~95 백분위).
- **겨울 원화(3·7)는 다른 종이다** — 지름 1.6px 무채색 점이 제자리에서
  명멸한다(트윙클). 이동 모델이 아니라서 이번 사이클의 파티클로는 재현
  대상이 아니다. 다음 사이클(마스크·라이트 스윕) 후보로 기록.

## 4. 판정 — 기본값 교정

| 값 | 이전 (잠정) | 실측 후 | 근거 |
|---|---|---|---|
| `TRAVEL_BASE`/`SPAN` (effects.ts) | 0.06 / 0.14 (51~171px/s) | **0.03 / 0.32** (26~299px/s) | 속도 슬라이더 양 끝을 실측 두 집단에 앵커: speed 0 ≈ 반딧불 표류, speed 1 ≈ 고속 불티 |
| `density` | 0.5 (풀 32) | **0.2** (풀 13) | sin(πu) 불투명도의 가시율 ~0.81 × 13 ≈ 10.5 — 모닥불 원화의 10~13개. 0.5는 레퍼런스의 3배 과밀 |
| `speed` | 0.5 | **0.4** (≈135px/s @평균 수명) | 기본 이펙트는 "불티"(호박색) — 표류(30)와 고속 상승(200+) 사이, 모닥불 P25 대역 |
| `sizePx` | 6 | **8** | 드로잉 지름 = 0.5~1.0 × sizePx, 평균 0.75×8 = 6px ≈ 실측 5.85px |
| `region` | (0.3, 0.55) 0.4×0.2 | **(0.25, 0.4) 0.5×0.35** | 실측 불티 구름을 출생 영역이 덮도록 (상승분은 travel이 더한다) |
| `periodMs` | 1500 | **1300** | 세그 적합 중앙값 1242ms, 군집 0.95~1.72s |
| glow `center` | (0.5, 0.62) | **(0.5, 0.74)** | 불꽃 실측 위치 |
| glow `radius`/`intensity`/베이스·깊이 | 0.18 / 0.6 / 0.75+0.25 | **유지 — 실측 확정** | §2.2 진폭 산술이 실측 대역과 일치 |
| `color` 2종, `LIFE`, `SWAY`, `FLICKER_HZ` | — | 유지 | 색은 M4 범위 밖(원화마다 다름 — 호박/초록/주홍/파랑, 운영자가 원화에 맞춰 지정). 나머지는 실측 대역 안 |

## 5. 하네스 재판정 — 계수 변경 후 5/5 PASS

`TRAVEL` 계수 변경 후 M0 하네스(프로덕션 경로) 재실행: **5/5 PASS, M2와 동일
수치** — 2회 렌더 비트 동일, 격리 띠 0.077, 단독 드로잉 0.49/255, 글로우 중심
0.620→0.643 (예측 0.644). 스파이크 픽스처의 도달 상한도 새 계수에서 y=0.36으로
격리 띠(0.30) 밖. 비용 참고치 동일(카메라 정지에서 on 2.32s vs off 2.32s).
유닛 614 그린.

## 6. 재현

```bash
cp <레퍼런스.mp4> artifacts/kv-obj-m4/out/reference.mp4   # 또는 KV_OBJ_M4_REF=<경로>
node artifacts/kv-obj-m4/locate.mjs     # → out/locate.json (불꽃 중심, std 프로파일)
node artifacts/kv-obj-m4/scan.mjs       # → out/scan.json (~25초)
node artifacts/kv-obj-m4/analyze.mjs    # → out/analysis.json + 콘솔 요약
node artifacts/kv-obj-m4/overlay.mjs    # → out/overlay-*.png (검출 육안 대조)
node artifacts/kv-obj-m4/probe.mjs      # 픽셀 값 스팟 체크
```

레퍼런스 mp4는 커밋하지 않는다(30MB 소재) — 세션에 다시 첨부해야 한다.
