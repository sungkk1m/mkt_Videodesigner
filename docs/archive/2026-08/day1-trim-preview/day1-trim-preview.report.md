## Learnings

**이미 절반이 있는지 먼저 본다.** "선처럼 보인다"는 신고의 실체는 이미 존재하는
윈도우의 폭이 1.4%였던 것이고, 엔드카드 루프도 렌더 엔진에 이미 있었다. 이번
사이클의 실제 작업량은 "없는 기능 추가"가 아니라 "있는 메커니즘의 노출"이었고,
그 판별이 Plan 단계 코드 조사에서 나왔다.

**시안 선승인(인터랙티브 목업)이 재작업을 제거했다.** 사용자가 ①번 요구를 시안으로
확정한 뒤 구현했기 때문에 UI 방향 수정이 0회였다.

**raw mouse 프로브는 스크롤을 직접 챙겨야 한다.** 검증 중 유일한 실패는 앱이 아니라
뷰포트 밖 좌표를 클릭한 프로브였다. `locator.click()`과 달리 `mouse.down()`은
auto-scroll이 없다.
